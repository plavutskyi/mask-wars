# Coin and network logos

Real logos only, never drawn or generated here. Each file below is vendored as published, made smaller with
[SVGO](https://github.com/svg/svgo) 4.0.1 (`--multipass`; the set's `class` attribute removed): square viewBox, no embedded
rasters, nothing loaded from elsewhere. `apps/web/app/near/coins.test.ts` fails if a listed coin or network has no file
here, if a file is not listed below, or if a file is not square, clean and small.

Coin and network names and logos are trademarks of their owners. They are shown only to identify the coin a person sends
or receives.
